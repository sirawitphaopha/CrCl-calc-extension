มอคอัปรอยต่อกล่องกับขอบจอ ให้เหมือนกางออกมาจากแถบฐาน

ฐานคือแถบเล็กที่ใช้ตอนพับเก็บ มีไอคอน คำว่า CrCl และค่าล่าสุด ทั้ง 3 แบบให้ฐานอยู่ที่ขอบจอตลอด ทั้งตอนพับและตอนกาง แล้วกล่องกางออกมาจากฐานนั้น ตัวกล่องเป็นแผงแคบ กรณีน้ำหนักปกติ

  • ภาพตัดมาเฉพาะฝั่งขวาของจอ ขนาดจริง สูง 577 จุดเท่าโครมของพี่กัน เส้นขอบขวาของแต่ละภาพคือขอบจอ
  • แต่ละแบบเรียงจากซ้ายไปขวาตามจังหวะ ตอนพับ กำลังกาง และกางเต็ม
  • ภาพกางเต็มกดได้จริง กดแถบฐานหรือปุ่มพับที่หัวกล่องเพื่อดูจังหวะพับและกาง ปุ่มอื่นในหน้านี้ยังกดไม่ได้
  • ติดขอบซ้ายจะกลับด้านเหมือนส่องกระจก

กล่องห้อยจากแถบ

ข้อดี เห็นชัดว่ากล่องออกมาจากแถบตอนพับ แถบอยู่ที่เดิมทั้งตอนพับและตอนกาง หัวกล่องต่อเป็นสีเดียวกับแถบ ใต้แถบมีมุมโค้งเว้าต่อเข้าขอบกล่อง
ข้อเสีย กล่องกว้างขึ้นเท่าแถบ 52 จุด และใต้แถบลงไปมีช่องว่างระหว่างกล่องกับขอบจอ

แถบยืดเป็นสันติดขอบ

ข้อดี แถบยืดลงจนสูงเท่ากล่อง กลายเป็นสันติดขอบจอตลอดแนว กล่องงอกออกจากสันเหมือนเปิดหนังสือ ดูติดแน่นกับขอบที่สุด
ข้อเสีย กว้างขึ้น 52 จุดเหมือนแบบแรก และสันสีเขียวยาวตลอดแนว ดูหนากว่าแบบแรก

กล่องลอยออกจากแถบ

ข้อดี กล่องลอยแยกจากขอบจอเล็กน้อย ดูเบา มีหางชี้กลับไปที่แถบ รู้ทันทีว่ากล่องมาจากตรงไหน
ข้อเสีย กว้างขึ้นราว 66 จุด และกล่องกับแถบเป็นคนละชิ้น ดูเชื่อมกันน้อยกว่าสองแบบแรก
