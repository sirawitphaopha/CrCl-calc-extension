**รอบ 2 ต้องมีช่องค้นหายา** (พี่กันสั่ง 5 ต.ค. 2569)

> "จดเพิ่มว่ารอบ 2 ต้องมีช่องค้นหายาด้วย"

- ข้อมูลยาที่ค้นได้ คือชุดเดียวกับตารางปรับตามไตในไอเดียสารานุกรมขนาดย่อมข้างล่าง · 🔴 `medical-data-safety` ห้ามเดา

## ไอเดียใหม่

### คำนวณขนาดยาตามน้ำหนัก และบอกว่ายาไหนใช้น้ำหนักแบบไหน (พี่กันเสนอ 3 ต.ค. 2569)

> "วันนี้วันใหม่เเล้ว เราคิดอันนึออก คำนวนขนาดยาตามน้ำหนัก เช่นวันนี้เราเจอ cef3 โโสเด็ก ถ้าใส่ใน ext อันนี้ด้วยก็ดีนะ ว่ายาไหนควรใช้ actual ideal BW จดไว้ๆๆ"

- **สถานะ:** ไอเดียที่จดไว้เท่านั้น · พี่กันยังไม่ได้สั่งทำ · ยังไม่ได้จัดว่าอยู่ก่อนหรือหลังรอบไหน
- **cef3 คือ ceftriaxone** พี่กันบอกเอง "cef3 ก็คือ ceftriaxone ไงงง tri = 3"
  - แคลร์ตีความผิดไปก่อนว่าเป็นยากลุ่มเซฟาโลสปอรินรุ่นที่ 3 แล้วเขียนลงไฟล์นี้โดยไม่ได้ถาม แก้แล้ว
  - Cef3 ในตัวอย่างโน้ตข้างล่างก็คือ ceftriaxone
- **แคลร์เข้าใจว่า:**
  - "โโสเด็ก" คือขนาดยาของเด็ก
  - อยากให้ส่วนขยายคำนวณขนาดยาจากน้ำหนัก และบอกว่ายาแต่ละตัวควรคิดจาก Actual BW หรือ Ideal BW
- **ของที่มีอยู่แล้วในรอบ 1:** กล่องคิด Actual BW · Ideal BW · Adjusted BW ให้อยู่แล้วในตารางน้ำหนัก 3 แบบ ไอเดียนี้ต่อยอดจากตรงนั้นได้

**ตัวอย่างโน้ตที่พี่กันเขียน** (ส่งเป็นภาพมาตามหลัง แคลร์พิมพ์ตามภาพทุกตัวอักษร)

> "เราจะเขียนประมาณนี้ ถ้าตอนร่าง note ก็ออกมาประมาณนี้ได้นะ เป็นไอเดีย อาจจะมีการปรับเปลี่ยน"

```
Note : Rx note

Cef3 ใช้ actual BW ใชการคำนวน
BW 16 kg
order Cef3 1300 mg/day
= 81.25 mg/kg
โดสเหมาะสม
```

- **ตัวเลขในตัวอย่าง:** 1300 ÷ 16 = 81.25 ตรงกับที่พี่กันเขียน
- **โน้ตที่ร่างออกมามี 5 ส่วน**
  1. ยาตัวไหนใช้น้ำหนักแบบไหน
  2. น้ำหนักที่ใช้คิด
  3. ขนาดยาที่สั่ง
  4. ขนาดยาต่อ kg ที่คิดได้
  5. สรุปว่าเหมาะสมไหม
- **โยงกับรอบ 3:** กดแล้วได้ข้อความ consult
- **ยังไม่เคาะ:** พี่กันบอกเองว่าเป็นไอเดีย อาจจะปรับเปลี่ยน
- 🔴 **ส่วนที่ 5 ต้องมีช่วงขนาดยาอ้างอิงของยาตัวนั้น** ระบบถึงจะบอกได้ว่าเหมาะสมหรือไม่ ช่วงขนาดยาต้องมาจากแหล่งอ้างอิงที่พี่กันยืนยัน ห้ามแคลร์ใส่เอง
- 🔴 **ข้อมูลยาห้ามเดา:** ต้องมีแหล่งอ้างอิงที่พี่กันยืนยันทุกตัว และเปิดสกิล `medical-data-safety` ก่อนเริ่มเสมอ
  - ยาแต่ละตัวใช้น้ำหนักแบบไหน
  - ขนาดยาต่อ kg และขนาดยาสูงสุด
  - ขนาดยาของเด็ก
- **ต้องคุยก่อนเริ่ม** (ยังไม่มีใครเคาะ)
  - ใช้กับผู้ใหญ่ เด็ก หรือทั้งสองกลุ่ม
  - ยาชุดแรกมีตัวไหนบ้าง
  - ใช้แหล่งอ้างอิงอะไร
  - อยู่ในกล่องเดียวกับ CrCl หรือแยกส่วน

### หน้าแรกแบบแอปมือถือ มีปุ่มเลือกเครื่องมือ (พี่กันเสนอ 5 ต.ค. 2569)

> "จริงๆเอาอันนี้ก็ได้นะ ส่วนชื่อเต็ม อาจจะเอาไว้ที่เเบนเน้อบนสุด เพราะอย่างที่เราบอก เค้า exten ตัวนี้ สุดท้ายเเล้วมันจะเหมือนสารานุกรม ที่กดมาหน้าเเรกมันจะคล้ยหน้าเเอบมือถือที่จะมีเลือกปุ่มว่าปุ่มนี้คำนวน CrCl ปุ่มนี้ขนาดยาเด็ก บลาๆ อะไรพวกนี้"

- **สถานะ:** ไอเดียที่จดไว้เท่านั้น · พี่กันยังไม่ได้สั่งทำ
- **อยากได้อะไร:** กดไอคอนส่วนขยายแล้วหน้าแรกเป็นปุ่มเลือกเครื่องมือ เหมือนหน้าแอปบนมือถือ เช่น ปุ่มคำนวณ CrCl · ปุ่มขนาดยาเด็ก
- **โยงกับงานอื่น:** สารานุกรมขนาดย่อมข้างล่าง · คำนวณขนาดยาตามน้ำหนักข้างบน · รอบ 2 เลือกยาแล้วบอกว่าต้องปรับตามไตไหม
- **ที่เกิดขึ้นแล้วเพราะไอเดียนี้:** หัวข้อในกล่อง CrCl ใช้ชื่อสั้น CrCl (Cockcroft-Gault) ชื่อเต็มไปอยู่บนหัวกล่อง (กำลังเลือกแบบในหน้าเกลาคำ)

### สารานุกรมขนาดย่อม เปิดดูขนาดยาได้ตอนใช้งาน (พี่กันเสนอ 3 ต.ค. 2569)

> "จริงๆคือนนั้นนมีบันทึกขนาดยาเด็กด้วยก็ดีนะ เพราะเราก็จำไม่ได้ เปิดดูตลอดเลย ถ้ามันเอาไว้เปิดดูตอนนั้นได้กูจะดี ประมาณว่ามันไม่ใช่เเค่เครื่องมือคำนวน เเต่เป็นสารานุกรมขนาดย่อม เราอาจจะใส่ตารางการปรับตามไตของยาบางตัวไว้ด้วย"

- **สถานะ:** ไอเดียที่จดไว้เท่านั้น · พี่กันยังไม่ได้สั่งทำ
- **อยากได้อะไร:**
  - บันทึกขนาดยาเด็ก เปิดดูได้ตอนนั้นเลย เพราะจำไม่ได้ ต้องเปิดดูทุกครั้ง
  - ตารางการปรับขนาดยาตามไตของยาบางตัว
  - ส่วนขยายไม่ได้เป็นแค่เครื่องมือคำนวณ แต่เป็นสารานุกรมขนาดย่อมด้วย
- **โยงกับงานอื่น:**
  - ตารางปรับตามไต เป็นข้อมูลชุดเดียวกับที่รอบ 2 ต้องใช้ (เลือกยาแล้วบอกว่าต้องปรับตามไตไหม)
  - ขนาดยาเด็ก เป็นข้อมูลชุดเดียวกับที่ไอเดียคำนวณขนาดยาตามน้ำหนักต้องใช้ตัดสินว่าโดสเหมาะสมไหม
- 🔴 **ข้อมูลทุกบรรทัดคือข้อมูลยา** ต้องมีแหล่งอ้างอิงที่พี่กันยืนยันทุกตัว แคลร์ห้ามเติมจากความจำ · เปิดสกิล `medical-data-safety` ก่อนเริ่ม
- **แหล่งข้อมูล: พี่กันจะเอาจาก UpToDate มาให้เอง**
  > "เดี๋ยวเราเอาจาก uptodate มาให้อยู่ละ"
  - พี่กันพิมพ์ตอนลืมสลับแป้น ต้นฉบับคือ `gfuJp;gikgvk0kd ียะนกฟะำ ,k.shvp^j]t` แคลร์แปลงแป้นกลับ
  - เป็นคำตอบต่อบรรทัดที่แคลร์เขียนว่าข้อมูลทุกบรรทัดต้องมีแหล่งอ้างอิงที่พี่กันยืนยัน
- **ต้องคุยก่อนเริ่ม** (ยังไม่มีใครเคาะ)
  - ยาชุดแรกมีตัวไหนบ้าง
  - ~~ใช้แหล่งอ้างอิงอะไร~~ UpToDate พี่กันเอามาให้ · ที่ยังต้องคุยคือจะบอกแหล่งอ้างอิงไว้คู่กับยาแต่ละตัวไหม
  - **repo นี้เป็น public**
    - UpToDate เป็นฐานข้อมูลแบบสมัครสมาชิก
    - ต้องเช็กข้อตกลงการใช้ก่อน ว่าเอาเนื้อหาไปเก็บใน repo ที่คนนอกเปิดอ่านได้หรือไม่
    - ถ้าไม่ได้ ต้องเลือกว่าจะทำ repo เป็น private หรือเก็บข้อมูลยาไว้นอก repo
